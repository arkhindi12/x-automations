  2. Klik "Add Account" → "Cookies Login"
  
  3. Isi form:
     • Username: your_username (tanpa @)
     • Cookie JSON: Paste SELURUH JSON dari Cookie-Editor

  5. Tunggu 5-10 detik
  
  6. Lihat hasil:
     ✅ "Cookies validated" → Klik Save
     ❌ Error → Lihat pesan error

    {

      "name": "auth_token",
      "value": "a1b2c3d4e5f6...",
      ...
    },
    {
      "domain": ".x.com",
      "name": "ct0",
      "value": "1a2b3c4d5e6f...",
      ...
    }
  ]
  
  Paste SELURUH JSON ini ke form "Cookie JSON"

┌─────────────────────────────────────────────────────────────────────┐
│ 🐛 COMMON ERRORS                                                    │
└─────────────────────────────────────────────────────────────────────┘

  "Cookie undefined"
    → Paste ke text editor dulu, baru copy ke form
  
  "AUTH_TOKEN_MISSING"
    → Export ulang dari tab yang sudah login (bukan incognito)
  
  "CT0_MISSING"
    → Refresh x.com lalu export ulang
  
  "Connection failed"
    → Backend mati, jalankan: ./restart-backend.sh
  
  "Rate limit"
    → Tunggu 15 menit atau jalankan: ./restart-backend.sh
